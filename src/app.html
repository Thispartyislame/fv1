How it works

Drag blocks from the left, wire outputs (right dots) to inputs (left dots), and turn the knobs on each block. The program on the right is real FV-1 assembly; an emulator runs the exact same machine code you will burn.

Blue cables carry audio, orange cables carry control signals (pots, LFOs). Click a cable to delete it, or drag it off an input.

Hearing it

Press Start audio. Then either turn on your guitar input, press Demo riff, load a recording, or record a loop. The looper holds your dry loop and the effect runs live on top, so you can keep changing the patch while it plays. Use headphones when monitoring a live input.

Limits that matter on the real chip

128 instructions, 32 working registers, 32768 samples (about 1 second) of delay RAM, 3 pots, 2 sine LFOs, 32 kHz sample rate. The status bar shows how much you have used. The looper in this app is for auditioning only; the chip itself can only loop about a second.

Editing aids: Ctrl+Z / Ctrl+Y (or ↶ ↷) undo and redo graph edits. The thin bar under each block's title is its output level; red means it hit the chip's limit. A/B keeps two versions of your patch and flips between them while a loop plays. Render WAV runs the current loop through the patch offline. Optimize code (Code tab) merges redundant instructions and shares registers with the same sound. On the Chip tab, Audition plays a stored slot with a short crossfade (like turning the program switch) and Knob legend writes a text list of what each knob does per slot. Ring Mod and Bit Crusher are new effects; the LFO now has sine, triangle, square, soft-square and saw shapes; Pots have taper and min/max.

Importing: “Import” in the header opens SpinASM text (.spn/.asm/.txt) in hand-edit mode, or a chip image (.hex/.bin) which is disassembled into the 8 bank slots. On the Chip tab, “Read chip → bank” does the same straight from your EEPROM. Imported code uses plain numeric delay addresses, so the RAM meter shows 0.

Dynamics & filters: Envelope turns playing level into a control signal (plug into Resonant Filter “freq” for auto-wah). Noise Gate goes before high-gain blocks. Compressor uses LOG/EXP gain computing. Resonant Filter is a state-variable filter; a Pot on “freq” makes a wah. Metal Dist is modeled on the character of a Fromel-modded Metal Zone (more gain, smoother clipping, tamed fizz, usable EQ with a sweepable mid), not its circuit. Hover over any dot or setting for a hint; while dragging a cable, valid drop targets glow green.

* “rate*” and “pitch*” inputs (pot-controlled LFO speed / pitch) write the LFO rate registers. The emulator follows the model used by the SpinCAD simulator; confirm the sweep range on real hardware. The pitch input sweeps the shift linearly between −N and +N semitones (it is not centred on unity).

Pitch shifting uses a ramp LFO and two crossfaded read heads. Short windows react fast but warble; long windows are smooth but add latency. Only 2 ramp LFOs exist, so at most 2 Pitch Shift blocks.

Before you burn a chip

The assembler is checked word-for-word against the open-source asfv1 assembler, but the emulator is not bit-exact with the silicon. Download the .spn and assemble it in Spin's own SpinASM at least once, and always test the first chip on the bench.
